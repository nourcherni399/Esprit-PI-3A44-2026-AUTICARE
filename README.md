AutiCare – Autism Support Desktop Application

Overview

This project was developed as part of a university academic program in Software Engineering (Academic Year 2025–2026).

AutiCare is a full-stack desktop application developed using JavaFX to support individuals with autism by providing a safe, interactive, and accessible digital environment. The platform enables users to manage autism-related services such as specialized product ordering, awareness modules, article publication, event participation, and appointment booking with specialists.

The application was designed with usability, accessibility, and modularity in mind while following modern software engineering practices.

Features
Product ordering system for autism-related products
Awareness and educational modules
Article writing and publishing
Thematic event management and registration
Appointment booking with autism specialists
User authentication and role management

Architecture

The application follows a layered architecture inspired by the MVC (Model-View-Controller) design pattern.

Model

Handles database entities and data management:

Users
Products
Articles
Events
Appointments
Modules
View

Built using JavaFX and FXML to provide an interactive graphical user interface.

Controller

Manages business logic, user interactions, and communication between the interface and the database.
